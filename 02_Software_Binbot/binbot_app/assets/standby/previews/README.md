# 固定图库预览

每个当前索引中的主题对应 `<id>.rgb565`：152 × 152 像素、按行排列、RGB565 小端、无文件头或行填充，每张 46,208 字节。32 张总计约 1.41 MiB，设备只为可见项分配内存。

这些图片包含固定的 20:00、2026-11-04、多云 22° 和统一的日程、待办、专注及媒体样例，只用于设置页图库。全屏表盘使用应用传入的实时数据。

在仓库根目录重新生成：

```sh
cmake --preset host-simulator
cmake --build build/host-simulator --target generate_standby_previews -j6
```

生成器为 `tools/generate_standby_previews.c`，使用原生主题渲染器，固定随机种子和预览动画位置。修改主题或样例数据后重新生成；主题渲染失败或回退为表情时，生成器会报错。发布脚本还会检查索引内所有主题及其图片。图片与源资源一起保存，日常编译设备程序可以直接使用。
